# 绘梨衣 · 数据库桌宠

SillyTavern 独立扩展。绘梨衣读取「龙血玄黄·数据库」原奶龙的任务提示通道，使用自己的动作与互动。`r`n`r`n兼容 SillyTavern **1.14.0–1.19.0**。旧版没有启动回调时会自行等待设置接口，新版回调重复触发也不会生成第二只桌宠。兼容细节见 `COMPATIBILITY.md`。

## 直接在酒馆安装

1. 酒馆顶部 → **扩展程序** → **安装扩展程序**。
2. 粘贴仓库地址：`https://github.com/dzsks/xiaohuizhuochong`。
3. 安装后刷新页面，确认扩展列表中的 **绘梨衣 · 数据库桌宠**启用。
4. 右键绘梨衣，或在扩展设置中点击 **查看任务小本子**。看到 **已连接数据库**，或 **数据库正在处理任务**，表示已找到数据来源。

## 点击与连点互动（v0.4.0 加入）

小本子标题只有 **绘梨衣的小本子**，去掉了版本号。普通点击用于互动，查看任务有独立入口。

| 操作 | 小绘的反应 |
| --- | --- |
| 轻点一下 | 挥手回应 |
| 短时间点两下 | 抱着小黄鸭轻摇 |
| 1.2 秒内点三下或更多 | 抱着本子躲一躲 |
| 2.6 秒内点六下 | 探头 → 抱鸭 → 挥手；播完恢复 |
| 按住不动约半秒 | 安心小憩；松开后继续 12 秒，轻点唤醒 |
| 拖动 | 被拎起，松手坐稳并保存位置 |
| 右键，或扩展设置「查看任务小本子」 | 查看任务与通知 |

聚焦小绘后，Enter/空格也能互动，Shift+Enter 查看小本子，方向键微调位置，Home 重置。手机可点按、连点或长按互动；查看任务从扩展设置进入。

单击立即回应，再根据后续点击次数改变反应，无需等双击判断结束。长按、拖动和点击分别处理，松手不会多算一次点击；多次连点的动作段也不会被后续点击反复重启。数据库忙碌和成功/错误反应优先，任务开始会结束本地互动。

采用原奶龙的点击计数、长按与拖动识别思路，动作和组合使用小绘自己的 16 张素材；没有复制奶龙的生气连段。本版本沿用 v0.3.1 清理后的图片，不新增图像下载。

继续使用原有的 **龙血玄黄·数据库**脚本及其原网址。本扩展不替换数据库入口，不复制数据库程序，不新增第二个数据库实例，不需要单独填写 API。

## v0.3.1：拖动减负、清理素材与动作衔接

- 拖动帧只移动小绘和更新摆动，使用 `translate3d`；任务本子和气泡独立放置。输入栏尺寸在开始拖动、输入栏改变或窗口变化时计算，不随每次移动重新读取。
- 数据库任务和通知继续同步，任务文字只在数据改变时刷新。拖动时收起小本子和气泡，松手保存位置；取消拖动或按 Escape 回到之前位置。
- 呼吸动画单独持续运行，切换姿势不会重启。切图过渡从 140 毫秒缩短为 50 毫秒，减少轮廓重影；拎起摆动和坐稳的缓动重新调整。初次加载直接出现在保存位置。
- 单独修正写记录、喝茶、伸懒腰、被拎起、坐稳、招手、探头七张图，去掉邻格头发或鸭子残片，补全裁掉的自身边缘。统一导出为 384×384 透明无损 WebP；抱鸭仍只保留手里的鸭子。
- 保留原扩展的设置和数据库只读观察器。没有改数据库加载代码或任务操作。

桌面浏览器中的 1280、375、320、430 宽度检查通过，含模拟触摸、取消拖动、松手最后坐标、位置保存、输入避让、任务进度和卸载清理。旧版与新版的实际鼠标拖动对照中，输入栏尺寸读取和任务本子改写由各 84 次降到 0 次。这是隔离预览的测量，不代表真实酒馆或所有设备的帧率；真实手机触摸和升级后任务联动仍需实际试用。

### v0.3.0 已有功能

- 鼠标拖动或手机按住拖动：小绘被轻轻拎起，随移动方向摆动；松手坐稳，靠近左右边缘会吸附。移动到的位置会保存，刷新后继续保留。
- 窗口变窄、手机横竖屏切换或键盘弹起，会把桌宠限制在可见区域并避开输入栏。小本子内有「回到默认位置」；扩展设置内也可以重置。
- 鼠标靠近时抱着小本子探头。键盘聚焦后，方向键微调，Shift + 方向键加速，Home 重置。轻点和长按的行为已按 v0.4.0 改为直接互动。
- 小本子里可以直接选喝茶、看书、折纸、抱小鸭、伸懒腰、小憩。数据库没加载时这些自身互动也能使用；忙碌时由任务反应接管。
- 动作预加载、解码后再切换；双图层短过渡，连续缓动由浏览器动画帧运行，不会随数据库轮询重启。拖动位置也随动画帧更新。
- 16 张透明无损 WebP，全部 384×384，总计约 2.1 MiB。前 12 张从原始图重新导出，新增 4 张独立互动图；不是放大旧版 192 像素压缩文件。所有姿势按统一基线对齐。

这些是独立姿势图结合连续位移动画和切换过渡；没有新增逐帧绘制的关节动画，细节动作仍受现有素材限制。

### 更新已有安装

将新版包解压后的文件覆盖上传至同一个 GitHub 仓库根目录（保留原 `assets` 文件夹中的文件结构），提交后在酒馆扩展管理中点击本扩展的更新按钮，刷新页面。在酒馆扩展列表确认版本 **0.5.0**；小本子标题不显示版本。拖动位置沿用本扩展设置。

## 数据库反应

- 接到任务：举起小本子；处理中：写记录；成功：展示完成记录；出错或警告：检查记录。
- 空闲：喝茶、看书、折纸鹤、抱小黄鸭、伸懒腰、小憩。
- 右键或扩展设置查看任务原文和最近通知；小本子中可送花，或让她换一边坐。
- 扩展设置可调整显示开关、大小、闲暇动作，以及原奶龙和原气泡是否隐藏。
- 抱鸭动作已去掉头顶的鸭子，只保留手里的那只。
- 手机显示最大 72 像素，避开输入框，图片与文字没有模糊或阴影。

## 数据同步范围

当前适配数据库 `naiv1` 的现有界面结构（源提交 `fd91407f84d7968473e82b90d93f22822cb3b259`）。本扩展只读该界面的忙碌状态、当前轮播任务与结果通知，自己控制绘梨衣的表现；不调用奶龙动作、不运行原任务按钮、不改表格或聊天。

任务进度随数据库原气泡的轮播同步，不宣称取得数据库尚未展示的全部并行任务。没有真实百分比时显示进度原文。任务不见了不会被当成成功，完成和错误只取自数据库的结果通知。

这一版本借助现有 Vue 渲染状态读取任务，数据库升级改变界面结构后可能需要适配。找不到兼容结构时会明确显示等待或不兼容，不会冒充连接成功。

若在数据库里关闭原奶龙，聚合忙碌状态可能不可用，此时只同步原气泡中的任务与通知。建议在数据库里保留奶龙开启，在**本扩展设置**中隐藏它；隐藏仅改变显示，不卸载数据来源。数据库静默或后台页面停止轮播时，本扩展也只能收到原通道实际提供的提示。

## 环境与恢复

- SillyTavern 至少 **1.19.0**；原数据库脚本应正常运行。
- 关闭或卸载本扩展，刷新页面即可恢复原奶龙显示，数据库加载代码不受影响。
- 如此前使用过实验包而把数据库代码改成了本地入口，可在原数据库脚本中恢复：

  ```js
  import 'https://fastly.jsdelivr.net/gh/AlbusKen/shujuku@naiv1/index.js'
  ```
