# 绘梨衣 · 数据库桌宠

这是一个安装到 SillyTavern 的独立 UI 扩展。它读取「龙血玄黄·数据库」已经显示出来的任务状态和结果通知，再让绘梨衣用自己的动作、点击互动和任务气泡作出反应。

## 当前版本：v0.5.9

**v0.5.9 的关键行为：小绘不会主动移动，右键可以开关小本子。**

- 只有用户手动拖动时，桌宠位置才会改变。
- 保留待机呼吸、点击互动、连点互动、长按小憩、拖动、任务气泡和任务停止按钮。
- 保留数据库只读同步，不复制数据库，也不替换数据库。
- 头顶的小黄鸭保留；抱鸭动作也保留手里的小黄鸭。
- 已从当前安装包移除左右跑步帧和自动散步逻辑。

旧版本曾经加入过自主移动、跑步和散步。那些逻辑已经从 **v0.5.8** 起回退，不应把旧版本的行为当成当前版本行为。

## 怎么判断 GitHub 仓库是不是最新版

按下面四处核对，全部显示 `0.5.9` 才算当前维护源已经更新完整：

1. 打开仓库根目录的 [`manifest.json`](manifest.json)，查看 `version` 是否为 `0.5.9`。
2. 查看本 README 顶部的“当前版本”是否为 **v0.5.9**。
3. 查看 GitHub 最近一次提交是否包含 `manifest.json`、`README.md`、`COMPATIBILITY.md` 和 `assets/` 的更新。
4. 如果使用压缩包，文件名应为 `绘梨衣桌宠-独立扩展-v0.5.9.zip`，解压后 `manifest.json` 仍应为 `0.5.9`。

酒馆扩展列表显示的版本是实际加载版本。只看到 GitHub README 已更新，还不能证明酒馆已经加载新版；更新扩展并刷新页面后再核对酒馆里的版本号。

## 直接在酒馆安装

1. 打开酒馆顶部的 **扩展程序** → **安装扩展程序**。
2. 粘贴仓库地址：`https://github.com/dzsks/xiaohuizhuochong`。
3. 安装或更新完成后刷新酒馆页面。
4. 在扩展列表确认 **绘梨衣 · 数据库桌宠** 的版本是 `0.5.9`。
5. 点击小绘，打开小本子；看到“已连接数据库”或“数据库正在处理任务”，说明已经找到数据库的数据来源。

仓库根目录应直接包含 `manifest.json`、`index.js`、`style.css` 等文件，不能多套一层外部文件夹。图片位于根目录的 `assets/` 文件夹内。

## 更新已有安装

### 通过 GitHub 仓库更新

1. 将新版文件覆盖上传到同一个仓库根目录，保留 `assets/` 的文件结构。
2. 提交 GitHub 更改。
3. 回到酒馆扩展管理，点击本扩展的更新按钮。
4. 刷新酒馆页面，确认扩展列表版本为 `0.5.9`。
5. 如果行为或图片仍是旧的，先重新加载扩展；仍未变化时使用 `Ctrl+F5` 强制刷新浏览器缓存。

### 通过压缩包检查

当前维护包：`绘梨衣桌宠-独立扩展-v0.5.9.zip`。

解压后检查：

- `manifest.json` 的 `version` 为 `0.5.9`；
- `index.js` 中的桌宠版本标记为 `0.5.9`；
- `assets/` 中没有当前版本使用的左右跑步帧；
- README 顶部和版本历史的最新条目都是 `v0.5.9`。

## 当前可用功能

### 点击和互动

| 操作 | 小绘的反应 |
| --- | --- |
| 轻点一下 | 挥手回应 |
| 短时间点两下 | 抱着小黄鸭轻摇 |
| 1.2 秒内点三下或更多 | 抱着本子躲一躲 |
| 2.6 秒内点六下 | 探头 → 抱鸭 → 挥手，播完恢复 |
| 按住不动约半秒 | 进入小憩；松开后继续休息约 12 秒 |
| 小憩时轻点 | 提前唤醒 |
| 拖动 | 被拎起，松手坐稳并保存位置 |
| 电脑右键 | 打开“绘梨衣的小本子” |

小本子标题固定为 **绘梨衣的小本子**，不显示版本号。普通点击不会打开页面；电脑端也可以从扩展设置进入小本子。聚焦小绘后，Enter / 空格可互动，Shift + Enter 可打开小本子，方向键可微调位置，Home 可重置位置。

### 手机操作

手机没有鼠标右键，使用下面的方式：

- 轻点或短按：互动；
- 按住约半秒：小憩；
- 继续按住约 1.4 秒：打开小本子；
- 按住并移动：拖动小绘。

输入框变高、键盘弹出、屏幕旋转或窗口变窄时，桌宠会限制在可见区域并避开输入框。小本子会自动选择上方、下方或侧边位置，尽量不遮住小绘。

### 数据库任务反应

- 接到任务：举起小本子；
- 任务处理中：写记录；
- 成功：展示完成记录；
- 出错或警告：检查记录；
- 空闲：喝茶、看书、折纸、抱小黄鸭、伸懒腰、小憩等。

任务处理中和成功/错误通知的反应优先于本地休闲动作。气泡提供数据库原任务的停止按钮时，小绘会显示 **停止任务**，点击后调用数据库原来的停止流程；没有停止能力时不会伪造按钮。

## 数据库同步边界

本扩展只读数据库当前界面提供的任务状态、轮播中的任务文字和结果通知：

- 不复制数据库插件；
- 不替换数据库入口；
- 不改表格、聊天、API 设置或数据库任务按钮；
- 不调用奶龙动作控制；
- 不宣称拿到了数据库没有展示的全部并行任务；
- 没有真实百分比时，显示数据库原来的进度文字。

当前适配数据库 `naiv1` 的现有界面结构。数据库未来如果改动 `DeskPetLayer`、`DeskPet` 或 `NoticeBubble` 等界面结构，小绘可能提示“数据库界面不兼容”，并保留原数据库桌宠显示。

建议在数据库设置中保留原奶龙和原任务气泡运行，再在本扩展设置中隐藏它们。这里的“隐藏”只改变显示，不会卸载数据库，也不会切断数据来源。

## 设置与恢复

在酒馆扩展设置中可以调整：

- 小绘显示开关；
- 桌宠大小；
- 空闲动作；
- 是否隐藏原奶龙和原气泡；
- 重置小绘位置。

关闭或卸载本扩展后，刷新酒馆即可恢复原数据库桌宠显示。数据库本身不需要回滚，也不要用旧版实验包覆盖数据库入口。

## 常见问题

### 更新后小绘还会自己移动

先在酒馆扩展列表确认版本。如果不是 `0.5.9`，说明酒馆仍在运行旧包；重新点击更新并刷新。`v0.5.7` 及更早版本包含主动移动逻辑，`v0.5.8` 起已经回退。

### GitHub 显示 0.5.9，但酒馆还是旧行为

GitHub 文件已经更新不等于酒馆已经重新加载。请依次执行：扩展管理更新 → 刷新页面 → `Ctrl+F5`。再检查酒馆扩展列表中的版本，而不是只看小本子标题；小本子标题从 v0.4.0 起不显示版本号。

### 小绘显示了，但提示没有连接数据库

确认原数据库仍在运行，并且没有被替换成本地实验入口。建议保留数据库原奶龙和任务气泡运行，只在本扩展设置中隐藏它们。数据库界面结构改变时，小绘会等待或提示不兼容，不会伪造“已连接”。

### 手机上没有右键，怎么打开任务本子

短按用于互动，按住约半秒进入小憩，继续按住约 1.4 秒打开小本子；也可以从酒馆扩展设置点击“查看任务小本子”。
